the 16 terminal colors and to Hangar's token kinds). No code, theme files or other assets of these

## Classic Monokai (2006)

- Used for: Ember (terminal scheme and file viewer theme)
- Origin: the Monokai color scheme for TextMate by Wimer Hazenberg, 2006
- Colors adapted and modified.

Ember uses only the publicly documented color values of the classic 2006 scheme (background
`#272822`, foreground `#F8F8F2`, pink `#F92672`, green `#A6E22E`, yellow `#E6DB74`, cyan
`#66D9EF`, purple `#AE81FF`, orange `#FD971F`, comment `#75715E`), mapped to the 16 terminal
colors with lighter bright steps; its light variant is Hangar's own. No theme file is included.
Ember is not based on Monokai Pro, a separate commercial product, and uses none of its colors.
