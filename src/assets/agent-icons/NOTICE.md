# Agent icons: sources and licenses

One `<id>.svg` per entry of the agent catalog (`src-tauri/src/agent_catalog.toml`). Each icon is a
24 × 24 tile in the product's color with either the product's mark in white or a monogram.

## Trademarks

The product names and marks shown here are trademarks of their owners. Hangar uses them only to
show which agent CLI a session runs (nominative use). Their use does not imply that any owner
endorses or is affiliated with Hangar. A license on the SVG data does not grant any trademark
right. Owners who want an icon changed or removed can open an issue.

## Monograms drawn for Hangar

No permissively licensed mark was found for these products, so Hangar draws its own monogram (the
catalog's letters, set in the system UI font) on a tile. No logo artwork is copied. The tile color
is taken from the product's website where one stood out, otherwise from Hangar's badge palette.
These files are part of Hangar and under its MIT license.
