# Local LLM server icons: sources and licenses

The top bar shows one small badge per local model server. The marks come from
[Simple Icons](https://simpleicons.org/) 16.37.0 (npm package `simple-icons`,
<https://github.com/simple-icons/simple-icons>), retrieved 2026-11-27 from
`https://cdn.jsdelivr.net/npm/simple-icons@16.37.0/icons/<slug>.svg`. Simple Icons is released
under CC0-1.0, and the
[Simple Icons disclaimer](https://github.com/simple-icons/simple-icons/blob/develop/DISCLAIMER.md)
applies. The path data is unchanged; only the `role` attribute and the `<title>` were dropped and
`fill="currentColor"` was added, so the mark takes the text color of the light and dark theme.
