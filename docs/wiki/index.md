## Decisions
- [[0011-work-log-and-daily-review]]: accepted: append-only work log per UTC day in the local data folder (`activity/`), start and end from the backend, working phases from the window, titles, programs, folders and times only, 90 days, 4 MiB per day; the daily review merges runs and phases per session and project as unions and adds the day's own commits, their files and today's uncommitted changes through the hardened git runner (sources: 0, updated: 2026-11-15)
- [[0010-command-guard]]: accepted: the agent gate also asks before a team session's agent runs a shell command matching a rule of `command-guard.toml` (force push, hard reset, forced clean, deleting outside the project, SQL drops, disk tools) or a built-in rule (too complex, script from stdin, too long, Hangar's own settings); one lexer per dialect, every hit counts, lexical path placing, remembered answers per rule and project, no answer or a full queue denies; Claude Code `Bash`/`PowerShell` and the Pi and OpenCode extensions, not Codex or private sessions; a safety net, not a sandbox (sources: 5, updated: 2026-11-14)
- [[0009-own-color-scheme-names]]: accepted: color schemes and file viewer themes carry own names (Harbor, Meridian, Studio, Anvil, Sundial, Velvet, Ember, Nocturne, Fjord, Ochre, Neon, Heather), 0.6.0 keys migrate, Ember redrawn from classic Monokai instead of Monokai Pro, origins and licenses in THIRD_PARTY_NOTICES.md; registry search open (sources: 0, updated: 2026-11-13)
- [[0008-private-and-team-sessions]]: accepted: one switch "Private | Team" per start; a team session has its own worktree, the agent gate and is shared with the team, a private one has neither; team capability comes from the catalog's capabilities and `hook_format` only, presence and claims are agent-independent (sources: 1, updated: 2026-11-12)
- [[0007-detachable-side-panel]]: accepted: the whole right panel (Notes, Changes, Files) detaches into one backend-created `panel` window; the main window stays the source of truth and pushes a validated context, the panel answers through `panel_to_main`; replaces the notes-only window (sources: 0, updated: 2026-11-12)
- [[0006-encrypted-project-notes]]: accepted: shared project notes in `.hangar/notes/`, one encrypted file per note, keys from the team crypto (signed `notes-keys` record) or a solo recovery code, Git conflicts kept as both versions; phase 1 (solo mode) as built (sources: 1, updated: 2026-11-13)
- [[0005-team-collaboration]]: proposed: several people and their agents on one project; requirements from the owner interview, end-to-end encrypted Hangar service, reservations, live file claims, merge queue (sources: 0, updated: 2026-11-08)
- [[0004-notes-per-working-folder]]: notes belong to the working folder, stored as .md in the app data folder, keyed by the normalized path; folder names `general` and `.trash` since 2026-11-08; shared notes in [[0006-encrypted-project-notes]] (sources: 0, updated: 2026-11-10)
- [[0003-program-versions]]: program versions via a `--version` call with timeout and cache; program icons; queries run in an own probe folder (sources: 0, updated: 2026-11-12)
- [[0002-version-scheme]]: versions X.Y.Z-Build (internally X.Y.Z+Build), build number from Git; the code always carries the upcoming version (sources: 2, updated: 2026-11-08)
- [[0001-foundation]]: foundation: Tauri 2, portable-pty, xterm.js, output flow, process tree (sources: 1, updated: 2026-11-07)
